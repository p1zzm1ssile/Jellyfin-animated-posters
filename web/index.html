Library Cover Maker

Add up to 5 videos or pictures, or pick a folder and let it choose 5 at random. Type your library name and get an animated WebP cover that cuts between moments from each one. Choose the moment for each video, or leave it random. Pictures get a slow zoom.

Drag to move the picture. Scroll or use the Zoom slider to resize it. Click a file in the list to preview it. Each video has its own slider for choosing the moment.

6 s

  1. Click Download animated cover (or right-click the animation → Save image as…).
  2. In Jellyfin, right-click the library → Edit images → upload it with type Logo.
  3. Add the CSS from the chat for that library, then press Ctrl+F5.
